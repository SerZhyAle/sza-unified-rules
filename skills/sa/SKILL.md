# sa - /spec-all, short

The same command as [spec-all](../spec-all/SKILL.md), with the same arguments (`/sa S0123`, `/sa <slug>`,
`/sa <key>:<id>`, `/sa <project-key>`, `/sa <idea text>`). Load that skill and follow it from Step 0; nothing here
differs.
